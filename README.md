# 我们在一起 · 纪念日网站

以 2024 年 11 月 17 日为第 1 天，实时计算在一起的天数。

## 访问地址

https://shiy07986-hub.github.io/

## 本地预览

双击 `index.html` 即可。

## 更新照片墙

1. 把照片（jpg / png / gif / webp）拷进 `photos/` 文件夹
2. 双击 `更新照片.command`（首次如被 macOS 拦截：右键 → 打开）
3. 脚本会自动刷新照片清单并推送到 GitHub，约 1 分钟后线上生效

## 技术说明

纯静态单页：液态玻璃（backdrop-filter）、照片墙视差与漂浮动效、
天数由浏览器本地计算，无任何后端服务；照片墙通过 `photos.js` 清单加载。
